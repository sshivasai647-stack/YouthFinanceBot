# Goal Tracker

## Purpose
Helps users set, track, and achieve financial goals.

## Key Functions
- `create_goal()` - Set a new financial goal
- `check_progress()` - Monitor progress toward goals
- `calculate_monthly_savings_needed()` - Required monthly savings
- `suggest_adjustments()` - Recommend changes to meet goals
